# aiTrends Reconstruction Studio integration

Adapted from the user's supplied `3D reconstruction/reconstruction-studio/engine/` kit (package version 0.1.0, aiTrends Reconstruction Studio plugin 0.2.0), for their Creatorize Personal Edition application. Original source headers are retained. The supplied kit does not include a general redistribution license; this notice does not grant one.

Creatorize adapters expose validated scene data, local map loading, owned resource disposal and deterministic animation through the existing editor/export renderer. The supplied standalone server, demo projects, virtual environment, account configuration and generated media are not included.

`topojson/` is topojson-client, copyright Mike Bostock (ISC license included). `data/` contains world-atlas Natural Earth and us-atlas Census topology; the respective package licenses accompany those files. These are schematic geographic outlines, not surveyed terrain, precise boundaries or satellite imagery. Three.js uses the app's existing licensed runtime and copied addons.
