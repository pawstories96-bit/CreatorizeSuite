# Legacy FBX conversion

`FBX2glTF.exe` is the upstream Windows x64 v0.9.7 release from
https://github.com/facebookincubator/FBX2glTF/releases/tag/v0.9.7

SHA-256: `8d90fb5e0a8d186a3d9a7ff8c75eaee541c3975ce4df0d80351f20092ae0877f`

The build preparation downloads and verifies this binary when missing. It is
included in desktop resources for local pre-FBX-7 imports. The upstream BSD
distribution notice is in `resources/licenses/FBX2glTF.txt`. Conversion operates
on a temporary upload copy; original character files are unchanged. This folder
contains no user character models.
